# Quick Start Guide - 2 Minutes

Get the AZ-104 exam app running in 2 minutes!

## 1️⃣ Extract ZIP (30 seconds)

Unzip `az104-app.zip` to your desired folder.

## 2️⃣ Open Terminal

Open Terminal/Command Prompt and navigate to project:

```bash
cd path/to/az104-app
```

## 3️⃣ Install (1-2 minutes)

```bash
npm install
```

Wait for "added XXX packages" message.

## 4️⃣ Run (30 seconds)

```bash
npm start
```

Opens at `http://localhost:3000`

## ✅ Done!

You're now running the AZ-104 exam app locally!

## Troubleshooting

### Error: "npm: command not found"
Download Node.js from https://nodejs.org/

### Port 3000 in use
```bash
npm start -- --port 3001
```

### Missing files
```bash
rm -rf node_modules
npm install
```
